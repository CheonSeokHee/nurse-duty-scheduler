# 간호사 3교대 듀티표 자동 생성기

Google 스프레드시트 + Apps Script(`Code.gs`)로 동작하는 간호사 듀티(Day/Evening/Night/Off) 자동 배정 도구.
설치·서버 불필요 — 시트에 코드 붙여넣고 메뉴 버튼만 누르면 한 달 듀티표가 자동 생성됩니다.

## 주요 기능
- 메뉴 **🩺 듀티표**: ①시트 세팅 ②자동 배정 ③규칙 검사 / 칸 넓히기
- 실행할 때마다 **다른 배치** 추천 (규칙은 동일하게 준수)
- **요청오프·요청근무**를 먼저 입력하면 그대로 고정하고 나머지를 배정

## 적용된 규칙 (설정 시트에서 변경 가능)
| 항목 | 값 |
|---|---|
| 하루 인원 | Day 3 · Evening 3 · Night 2 (인원수에 맞게 조정) |
| 나이트 | 1~3일 블록, 매일 차지 1명, 전원 나이트 수 균등 |
| 3일 나이트 뒤 | 2오프 (1~2일 블록 뒤 1오프) |
| 연속근무 | 최대 4일 |
| 연속오프 | 차지 최대 3일 / 액팅 최대 2일 |
| Evening 인원 | 하루 최대 3명 |
| 차지 | 모든 근무에 1명 이상 |
| 1인 오프 | 10~11개 |
